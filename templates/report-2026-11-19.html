rejovi-admin

por confirmarNext 16.4.6 · NGINX + PM2 en VPS Ubuntu
Dependencias
Sin hallazgos: las 461 dependencias están en versiones corregidas.
NGINX
CVE-2026-123007 (HTTP/2): no afectado según el repo, porque deploy/nginx/*.conf no activa http2. CVE-2026-118899 (TLS 1.3, CVSS 8.7, denegación de servicio): probablemente afectado. Hay listen 443 ssl en admin.rejovi.com.conf:29, y el options-ssl-nginx.conf de Certbot activa TLS 1.3. También conviene revisar CVE-2026-123633 si alguien activa HTTP/2 con proxy. La versión instalada no está en el repo: verifícala en el servidor.
Verificar
nginx -v
grep -rn "http2" /etc/nginx/
apt list --upgradable 2>/dev/null | grep nginx
Mitigar
sudo apt update && sudo apt install --only-upgrade nginx && sudo nginx -t && sudo systemctl reload nginx
Si Ubuntu aún no publica el parche: instala NGINX 1.30.7 desde el repositorio oficial de nginx.org o, como medida temporal, fija ssl_protocols TLSv1.2; en los bloques 443, debajo del include de Certbot.

Las carpetas locales de tu equipo no se revisaron porque no hay ninguna compartida por Remote Control. Las versiones mínimas recomendadas vienen de OSV; antes de desplegar, confirma con npm ls o go list -m all después de actualizar.
